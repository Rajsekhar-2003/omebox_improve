Frequently Asked Questions

How do I receive files without login?
Simply enter the 6-digit code provided by the sender in the input field above. No registration or login required. The content will be available for immediate download.
What if the content is password protected?
If the sender set a password, you'll be prompted to enter it after providing the access code. The password must be shared separately by the sender. This adds an extra layer of security for sensitive content.
Can I receive files from Android to iPhone?
Yes! OmeBox works seamlessly across all platforms. Whether files are sent from Android, iPhone, PC, or Mac, you can receive them on any device with a web browser.
How long are received files available?
Files are available based on the expiry time set by the sender (from 15 minutes to 7 days). After expiry, content is automatically deleted from our servers.
Is it safe to receive files?
Yes — transfers are encrypted in transit (TLS). Files are automatically deleted after expiry, and we do not require any personal information to receive them.
What file types can I receive?
You can receive any file type including documents (PDF, DOC, XLS), images (JPG, PNG, GIF), audio (MP3, WAV), video (MP4, MOV), archives (ZIP, RAR), and code files.
